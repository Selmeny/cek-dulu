# Cek Dulu

Static site in Bahasa Indonesia. A person who is not an IT worker opens one daily event and does one safer action.

The home page lists events in ordinary words. A short check can be forwarded. Answers stay in the browser.

## Commands

```sh
npm install
npm run dev
npm run check
```

`npm run check` builds the site and checks the pages, the source links, and the short check.

## Publish

GitHub Pages serves the site from `main` at `https://selmeny.github.io/cek-dulu/`.

The site does not use an account, a stored form, or third-party analytics.
